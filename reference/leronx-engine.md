LeronX Engine (Leron-X/leronx) — open-source AI video generation pipeline.
- GitHub: https://github.com/Leron-X/leronx
- Stars: 480, MIT license, Python 3.10+, FFmpeg 5.0+
- Создан: 2026-06-26, активно обновляется
- Модули: script gen, scene planning, voice synthesis (TTG 11 lang), FFmpeg render, subtitles, asset matching (Pexels/Pixabay), plugin system
- Проприетарное: cloud rendering, auth (Firebase), billing (Stripe), desktop app (Electron/Tauri)
