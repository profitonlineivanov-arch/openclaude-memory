Agent-Reach (Panniantong/Agent-Reach) — CLI инструмент, дающий AI-агентам доступ к интернет-платформам без API-ключей.
- GitHub: https://github.com/Panniantong/Agent-Reach
- Stars: 51 620, MIT license, Python
- Создан: 2026-02-24, активно обновляется
- Совместим: Claude Code, OpenClaude, Cursor, Windsurf и др.
- Поддерживаемые платформы: любые сайты (чтение), YouTube (субтитры+поиск), RSS, GitHub (публичные+приватные), Twitter/X, B站, Reddit (с конфигом), 小红书
- Без конфига: чтение любых сайтов, YouTube, RSS
- С конфигом: поиск (MCP, бесплатно), приватные репо GitHub, Twitter поиск/лента
- Фичи: cookie только локально, мульти-бэкенд (автопереключение при блокировке), agent-reach doctor диагностика
- Вердикт начальный (2026-07-06): не пригодится для текущих задач (2x2, 1224, PinFlow, hanma.ru)
- Agent-Reach НЕ качает видео — только текст/субтитры/поиск. Для скачивания видео нужен yt-dlp или другой загрузчик.
- Переоценён (2026-07-06): YouTube заблокирован RKN в РФ → yt-dlp не работает из Termux. Agent-Reach с мульти-бэкенд маршрутизацией может быть полезен для обхода блокировок. У пользователя есть прокси (138.59.207.154:9963 HTTP).
- Уточнение (2026-07-06): Agent-Reach НЕ качает видео — только текст/субтитры/поиск. Для задачи скачивания видео (тестовый контент для PinPilot) не подходит. Нужен отдельный загрузчик с обходом антибота YouTube.
- Вердикт: отложен — полезен для доступа к информации с заблокированных платформ, бесполезен для скачивания медиафайлов.
