**Новая страница `/trigger`:**
- Параметры: глубина истории, кол-во тиражей (1-50, default 10)
- Карточки тиражей: для каждого тиража 4 позиции, каждая с 3 типами триггеров (гориз., прав.диаг, лев.диаг)
- Клик по строке триггера → раскрытие деталей совпадений (AC, триггер, тираж найден, след.тираж, хэш)
- Тепловая карта: последние 20 тиражей (оранж=триггер AC, красн=другие AC, зелён=свободное)

**Цвета в таблице «Качество анти-кандидатов»:**
- **Зелёный** (`free-green`) — AC сработал: число НЕ было в AC, но выпало в результат. AC корректно исключил другие числа
- **Красный** с `!` (`ac-red`) — провал AC: число было в списке AC, но всё равно выпало. Tooltip показывает детали (сколько AC, от каких анализаторов)
- **Без цвета** — нет AC для этой позиции (ни один анализатор не дал исключений)

## Таблица качества анти-кандидатов (26 мая 2026) — ВЫПОЛНЕНО

Коммит: `550a3f3` на ветке V7.

Тепловая карта заменена на таблицу «Качество анти-кандидатов» — показывает **реальные** AC каждого прогноза и их совпадение с результатами тиража.

**Что изменено (2 файла):**
- `beams_api.py` — новая функция `get_ac_quality_history(limit)`, читает `anti_candidates_history` + `predictions_v4`
- `dashboard_2x2.py` — новый API `/api/ac_quality_history`, замена `renderHeatmap` → `renderACQuality`

**Логика таблицы:**
- Для каждого из последних N прогнозов (по умолчанию 20): какие AC были применены Селектором
- **Зелёное** — AC сработал: число исключено и НЕ выпало
- **Красное** (с `!`) — провал AC: число исключено, но ВЫПАЛО в результат
- Tooltip при наведении: детали (сколько AC, от каких анализаторов)
- Данные из `anti_candidates_history` — реальные AC, не текущие

## Разбивка AC по анализаторам (26 мая 2026) — ВЫПОЛНЕНО

После вопроса пользователя «какой из источников даёт качественные анти-кандидаты» — добавлена per-analyzer детализация в таблицу AC quality.

**Что изменено (2 файла):**
- `beams_api.py` — `get_ac_quality_history()` теперь возвращает `analyzer_details` для каждой позиции: `{analyzer_name: {count, hit, hit_nums}}`
- `dashboard_2x2.py` — `renderACQuality()` показывает mini-бейджи под номером позиции: `TB:5`, `Tr:3`, `DT:2`, `Mo:4`

**Бейджи:**
- Зелёный (`az-ok`) — анализатор НЕ дал AC, который попал в результат (AC сработал)
- Красный (`az-fail` + `!`) — анализатор дал AC, который провалился (число было в AC, но выпало)
- Сокращения: TB=triple_beam, Tr=trigger, DT=diagonal_trigger, Mo=morse
- Tooltip на бейдже: полное имя анализатора, кол-во AC, какие числа провалились
