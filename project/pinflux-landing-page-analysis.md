## PinFlux Landing Page (pinflux.in)

**Тип:** Long-form sales page для Pinterest-автоматизатора Pinflux 2 (Teknikforce)

**Структура (20 секций):**

| # | Секция | Назначение |
|---|--------|------------|
| 1 | Hero | "0→150k visitors in 30 days" + видео + CTA |
| 2 | Pain points | "Stop buying useless products" + иконки AI-фич |
| 3 | Social proof | 3,000+ активных пользователей |
| 4 | Features list | 9 чеклистов (найти пины, расписание, репин, follow/unfollow) |
| 5 | Why Pinterest | Сравнение с FB/Google/Twitter — трафик дешевле, конкуренция ниже |
| 6 | Pain paragraph | "You need traffic" — болевой копирайтинг |
| 7 | AI automation | 4 блока: AI-посты, рерайт заголовков, рерайт описаний, авто-рерайт |
| 8 | 3 steps | Connect → Set up → Watch traffic |
| 9 | Demo video | Видео-демонстрация |
| 10 | Niches | 6 карточек (ecom, блогеры, оффлайн, аффилиаты, social, vendors) |
| 11 | Automation features | Search/Pin/Repin/Follow/Content |
| 12 | Interface screenshots | Скриншоты UI + фичи-чеклисты |
| 13 | Before/after lists | "Stop doing X" / "Now you can Y" |
| 14 | Training bonus | Видео-курс в подарок |
| 15 | About company | Teknikforce, 4.9★, 100k users |
| 16 | Testimonials | 3 отзыва с фото |
| 17 | Pricing | Monthly $27 / Yearly $97 |
| 18 | Guarantees | 30 дней возврат, 24/6 чат |
| 19 | FAQ | 6 вопросов |
| 20 | Footer | Ссылки, соцсети |

**Дизайн:** тёмно-синий фон hero, зелёные CTA-кнопки, карточки с тенями, скриншоты интерфейса, градиенты.

**Копирайтинг-стиль:** long-form sales letter, pain-agitate-solve, повторяющиеся CTA, социальные доказательства, гарантии риска.

**Цель:** эталон для построения лендинга PinFlow.

**Why:** пользователь хочет аналогичный лендинг для PinFlow.
**How to apply:** при создании лендинга — использовать ту же структуру секций и стиль копирайтинга, адаптировав под PinFlow.
