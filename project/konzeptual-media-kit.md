Издательство «Концептуал» — медиакит 2026. Статический одностраничный сайт на чистом HTML/CSS/JS (без фреймворков), located at `E:\sites\kworks\Концептуал\`.

**About:** Publishing house run by Антипин Константин Валерьевич. 17 years on market (since 2008), TOP-50 Russian publishers. Topics: history, politics, science, economics, Soviet textbooks, children's literature, ZOZH. Website: konzeptual.ru.

**Site structure:** 6 full-screen sections (Home, About, Directions, History timeline, For Authors, Contacts/Team). Navigation with mobile burger menu.

**Tech:** Dark theme (#0a182c bg, #cca353 gold accent), Playfair Display + Montserrat fonts (Google Fonts), inline CSS, minimal JS (just mobile menu toggle). Media query at 992px for responsive.

**Files:** index.html (all content), images/ (80+ extracted PDF images + book covers), previews/ (15 page PNGs), PDF presentation in root, favicons, site.webmanifest (still has default "MyWebSite" values — not customized).

**Notable:** site.webmanifest has uncustomized defaults. No external CSS, no analytics, no SEO meta tags (og:*, description), no lazy loading on images.
