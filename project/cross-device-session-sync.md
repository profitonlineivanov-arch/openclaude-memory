type: project
---

**Цель:** Начать сессию на смартфоне → закрыть → продолжить на ноутбуке → снова на смартфоне.

**Исследовано (2026-07-06):**
- Сессии OpenClaude: `~/.openclaude/sessions/<pid>.json` (метаданные), `history.jsonl` (вся история, 1482 строки), `session-env/<uuid>/` (пусто)
- history.jsonl — единый файл на все сессии, merge conflict при синхре с двух устройств

**Обсуждалось 3 варианта:**
1. Git-ветка на устройство — каждая машина пишет свою историю в отдельную ветку
2. Экспорт/импорт отдельных сессий JSON → git push/pull
3. ruflo session MCP инструменты

**Статус:** Отложено. Пользователь вернётся позже.

**Why:** Пользователь работает на 2 устройствах (Android Termux + Windows ноутбук) и хочет продолжать диалоги на разных машинах.
**How to apply:** При возвращении к теме — напомнить 3 варианта и спросить предпочтение.
