Пользователь явно потребовал изменить UI выбора досок в PostSettingsActivity:

- **НЕ** text input с несколькими досками (ни через запятую, ни по одной в строке)
- **ДОЛЖЕН БЫТЬ** выпадающий список (dropdown/spinner) с ОДНОЙ доской
- Доски загружаются из аккаунта Pinterest

**Цитата пользователя:** "не должно быть несколько досок, ни через запчтую, ни по одной в строке. должна быть одна доска, которую пользователь выбирает из погруженного списка из аккаунта."

**Why:** Пользователь хочет постить в одну доску за раз. Multi-board создаёт путаницу и не соответствует реальному workflow.

**How to apply:**
- `showBoardSelectorDialog` заменить с `setMultiChoiceItems` на `setSingleChoiceItems`
- `targetBoardsInput` (TextInputEditText) либо скрыть, либо сделать readonly (показывать выбранную доску)
- `saveSettings` обновить для сохранения одной доски вместо списка
- Реализовать после подтверждения что доски грузятся (сначала починить загрузку)

**Статус:** Не реализовано. Ждём подтверждения что `pinflow-user-boards.apk` загружает доски.
