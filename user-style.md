User types quickly in Russian with frequent typos and abbreviations (e.g. "помнтшб" instead of "помнишь", "ввполнять" for "выполнять"). Uses mobile keyboard in Termux. Prefers casual, brief exchanges — no need for formal language. Каменный стиль включён: лаконичность соблюдена. Responds well when I summarize previous context to orient them. Gets visibly frustrated when asked to do tedious manual steps — expects the agent to handle things autonomously ("давай сам!"). Don't drag them through multi-step workarounds when the agent should be doing it.

**How to apply:** Keep responses short and casual. Don't over-explain. When the user asks "where did we leave off", check memory and give a quick recap rather than asking clarifying questions first.
