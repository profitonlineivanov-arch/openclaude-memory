description: Провал задачи по анализу итераций Селектора
type: feedback
---

**Rule:** НЕ начинать выполнение задачи без предварительного изучения документации и составления плана на одобрение.

**Why:** Пользователь четко сообщил: "сначала изучить документацию, чтобы понимать суть системы, а потом составить план на одобрение перед выполнением". Игнорировал это требование, начал делать код вслепую. Результат — потерянное время, неверный подход, пользователь отказался продолжать.

**How to apply:** Когда пользователь говорит "сначала изучить → потом план → потом делать", буквально следовать этому порядку. Не запускать никакие процессы, не писать код, не менять конфиги до получения явного одобрения плана.
