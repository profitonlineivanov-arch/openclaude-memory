**Правило:** Для UX-подсказок в PinFlow писать текст прямо в интерфейс (AuthActivity), а не в README.md.

**Why:** Пользователь указал, что будущие пользователи НЕ читают README во время авторизации. Им нужна подсказка на экране в момент входа.

**Как применять:**
- Когда добавляется инструкция по авторизации/настройке — помещать в UI: `statusText`, dialog, Toast
- README может дублировать для истории, но не быть единственным местом
- Для PinFlow критичные шаги (например, «перейти в профиль после входа») — обязательно в интерфейс
