**Правило:** Инструкции по авторизации в PinFlow должны быть встроены в UI (`AuthActivity`), а не только в README. Текст должен быть компактным, чтобы не перекрывать WebView.

**UX Решение (2026-06-11):**
Использовать сворачиваемую подсказку:
- Тизер: `▶ Подсказка` (выделен красным, жирный).
- По клику: раскрывается полный текст с инструкциями.
- Повторный клик: сворачивается (`▼ Подсказка`).

**Критические шаги для пользователя:**
1. После входа выбрать «Продолжить в браузере» (не приложение Pinterest).
2. Перейти на страницу своего профиля.
3. Нажать «Подтвердить» для извлечения никнейма.

**Why:** Большой объем текста в верхней части экрана закрывает значительную часть WebView, мешая процессу авторизации.

**Как применять:** При любых правках экрана авторизации сохранять механизм сворачивания подсказки.
