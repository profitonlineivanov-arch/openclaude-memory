Исследования production-кода проводить на удалённом сервере, а не на локальных копиях.

**Why:** Пользователь указал, что серверный код — авторитетный источник. Локальные копии (`C:\Users\admin\Downloads\`) могут отличаться от production. Пользователь явно сказал: "Тебе нужно произвести исследование на удаленном сервере, а не на локальном!" Также: "нужно непременно на сервере, там БД" — для анализа данных (исторические тиражи, статистика) сервер единственный источник, т.к. БД с ~25k тиражей существует только там.

**How to apply:** Для проектов 2x2 и 1224 — SSH на `root@45.146.164.144` (НЕ openclaw — home dir не существует, сессия падает через секунды). Пути `/root/projects/2x2/` и `/root/projects/1224/`, venv `/root/venvs/2x2/`. Читать файлы через SSH. Не пытаться клонировать с GitHub для анализа данных — в репо нет БД. Локальные копии использовать только для reference/документации.
