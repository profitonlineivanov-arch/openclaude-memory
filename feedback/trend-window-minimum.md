Для краткосрочного анализа трендов использовать окно не менее 21 дня (не 7 дней).

**Why:** 7 дней для конкретного hour+dow — это всего ~7 тиражей, недостаточно для понимания тенденции по дням недели. Пользователь хочет видеть тренды за 2-3 недели минимум.
**How to apply:** При настройке окон анализа в timing analyzer и аналогичных системах — краткосрочное окно >= 21 день. Применено в hourly_timing_analyzer.py (7d → 21d для trend adjustment).
