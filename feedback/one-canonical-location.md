---
name: One canonical location for artifacts
description: Don't duplicate artifacts (APKs, files) across multiple paths without explicit user need — keep one canonical location
type: feedback
---

Не дублировать артефакты (APK, логи, скачанные файлы) в несколько мест «на всякий случай». Одна каноничная локация — достаточно.

**Why:** 2026-06-08 после сборки `pinflow-1031.apk` я скопировал его в `~/storage/downloads/` И в `~/pinflow-1031.apk` для «удобства». Пользователь ответил: «зачем два места? это чтобы у меня побыстрее оно закончилось вместе с моим терпением?» — воспринял как лишнюю трату времени и места. Удалил дубль, переспрашивать не стал.

**How to apply:**
- Поместил файл в Downloads / стандартную локацию (~/storage/downloads/ для Android) → **стоп**, не копируй в домашнюю директорию или ещё куда-то
- Если хочется «подстраховаться» вторым путём — спросить пользователя сначала, а не делать молча
- То же для логов, скриншотов, временных отчётов
- Симметрично: не плодить дубли MCP-серверов, aliases, venv-копий и т.д. без запроса
- Если уже создал дубль и пользователь заметил — извиниться коротко и удалить без лишних объяснений
