description: ollama list пустое — OLLAMA_MODELS задан как User var, Ollama не видит. Нужен System-level env var. НЕ перемещать модели!
type: feedback
---

Когда `ollama list` пустое, а манифесты есть в `D:\Ollama\models\manifests\` — корень проблемы: `OLLAMA_MODELS` задан как **User** переменная, а Ollama работает в **системном** контексте и не видит её.

**Why:** Пользователь уже потратил огромное количество токенов на эту проблему. AI каждый раз заново исследует вместо немедленного фикса.

**How to apply:** 
1. Сразу сказать: "OLLAMA_MODELS нужно задать как системную переменную через Win+I → Переменные среды → системные."
2. НЕ перемещать модели, НЕ делать junction, НЕ копировать. Модели на D — не трогать.
3. НЕ исследовать заново — проблема и решение известны.
4. Не пытаться taskkill/перезапуск — это НЕ решает проблему с User vs System env var.
