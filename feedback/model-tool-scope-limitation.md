Model management tools (Ollama, LM Studio, etc.) can operate independently. **Why:** An external model managed by one client (e.g., via LM Studio GUI) may not be visible to the core system tool's command list (`ollama list`). The displayed output of a tool is limited strictly to what that tool detects/manages. **How to apply:** When investigating local environment issues, always verify which specific tool or service manages a resource (e.g., Ollama API vs GUI) before assuming the scope of detection.
