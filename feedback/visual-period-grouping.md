---
name: Visual period grouping preference
description: User prefers grouped block visualization over individual row highlights when showing time-based patterns
type: feedback
---

При визуализации временных периодов — группировать consecutive элементы в блоки с подписями, а не подсвечивать отдельные строки.

**Why:** Пользователь хочет визуально сопоставлять предполагаемое благоприятное время с фактическим. Отдельные подсвеченные строки не дают видеть периоды — нужно видеть блоки с метками времени и hit rate.

**How to apply:** При любой визуализации time-based данных (тиражи по часам, прогнозы по периодам) — использовать блочную группировку с badge-подписями (время + метрика), а не точечную подсветку.
